# 0.8.2 番剧和视频合集可以互转，合集管理更顺手！

0.8.2 把番剧和视频合集打通了，也把合集本身做得更像一个能长期整理的地方：可以改名、打分、写短评，还能看到这一组的合计。

本次重点：

- 转换：番剧和视频合集可以右键互转，单集能单独查看和搜索，封面和播放进度也会带过去
- 合集面板：点进合集后，左侧可以直接改名称、简介和标签，给整组打星、写短评
- 合计：游戏合集汇总游玩时长和打开次数，番剧合集汇总观看时长和播放次数
- 合集内容：在合集里拖入或导入时不再挑文件类型，认不出的文件记成「其它」
- 布局：一行放几张卡片改到页面配置里，卡片和标题不再跟着缩小，标题最多显示两行
- 界面：搜索框移到左侧筛选栏顶部，添加、创建合集等操作移到标题同一行
- 筛选：新增「文件夹 / 不是文件夹」，方便把合集和散落文件分开

## 新功能

### 番剧与视频合集互转

- 番剧右键可以「转换为视频合集」，每一集都会变成可以单独查看和搜索的资源
- 转换前会告诉你会新增多少条数据，原来的番剧记录会换成同名合集
- 视频合集右键可以「转换为番剧」，要求这些视频都在同一个文件夹里
- 收成番剧后，单集记录会从页面上拿掉，但封面、播放进度、演员和标签都会带进番剧
- 合集里如果还有视频以外的文件，会提示这些文件留在页面上，不再属于这个合集

### 合集侧边面板

- 点进合集后，左侧可以直接修改这一组的名称、简介和标签，不用再打开编辑窗口
- 可以给整个合集打星、写短评，和普通资源一样
- 面板里会显示成员合计的时长和次数：游戏合集汇总游玩时长和打开次数，番剧合集汇总观看时长和播放次数
- 页面没有对应字段时不会多出无关的合计行；自定义页面里成员自带的数据也能汇总

### 合集不再挑文件类型

- 在合集里拖入、添加或批量导入时，不再受当前页面类型的限制
- 认得出的文件按它自己的方式打开，认不出的会记成「其它」
- 电影合集里放花絮、游戏合集里放攻略或补丁，都不会再被拦下

### 文件夹筛选

- 左侧筛选新增「文件夹 / 不是文件夹」，可以把合集、番剧和目录，与单个文件分开查看
- 合集会直接算作文件夹，番剧和目录也算；exe、mkv、pdf 这类单个文件算「不是文件夹」
- 页面配置里可以直接添加这个筛选器，也可以手动勾选放在哪一页

## 体验优化

### 卡片与布局

- 资源页右上角不再用百分比缩放卡片，一行放几张改到页面配置的基础设置里，可以填 2 到 10，默认 4 张
- 卡片直接平分这一行，封面和标题的字号保持不变，不会因为一行多放几张就把字缩得看不清
- 页面配置里不再需要填写最小宽度和最大宽度，排版只看一行几张
- 整个界面的缩放仍然保留，想放大缩小界面时照常使用
- 卡片标题最多显示两行，放不下一行的长名字可以换行，超过两行才省略

### 页面操作

- 搜索框移到左侧筛选栏最上面，固定在那里，下面的筛选条件滚动时它不会跟着跑
- 添加、创建合集、批量导入和多选移到页面标题同一行，不再单独占一条工具栏，列表能多留一点高度
- 每个页面都可以在页面配置里单独设置自己的一行卡片数

## bug 修复

- 合集里面的资源会跟着当前排序，按名称、时间或其他字段排时，不再固定成加入合集的顺序
- 页面根目录排序时，合集和单独的文件按同一规则排列，不再总是把合集放在最前面
- 按同一模板新建页面后，左侧筛选和编辑时的标签不再带出原来那一页的标签，每一页只显示自己资源上用过的标签

0.8.2 connects anime and video collections, and makes collections a better place to organize things over time: rename a group, rate it, leave a short review, and see its totals.

Highlights:

- Conversion: turn an anime into a video collection or back from the right-click menu; episodes become individually viewable and searchable, and covers and playback progress come along
- Collection panel: edit the group's name, description, and tags on the left, and rate or review the whole collection
- Totals: game collections sum play time and launch count, while anime collections sum watch time and play count
- Contents: drop or import anything into a collection without being limited by page type; unrecognized files are stored as "Other"
- Layout: set cards per row in the page config; cards and titles no longer shrink, and titles wrap to at most two lines
- Interface: the search box moves to the top of the left sidebar, and add/create-collection actions move onto the title row
- Filtering: a new Folder / Not a folder filter separates collections from loose files

## Features

### Converting between anime and video collections

- Right-click an anime and choose Convert to video collection; every episode becomes a resource you can view and search individually
- Before converting, the app tells you how many records will be added, and the original anime record is replaced by a collection with the same name
- Right-click a video collection and choose Convert to anime; all videos must live in the same folder
- After converting, the individual episode records are removed from the page, while covers, playback progress, actors, and tags carry over to the anime
- If the collection also contains non-video files, the app notes that they stay on the page and no longer belong to the collection

### Collection side panel

- Inside a collection, edit the group's name, description, and tags directly on the left without opening an edit dialog
- Rate the collection and write a short review, just like a regular resource
- The panel shows totals for its members: game collections sum play time and launch count, while anime collections sum watch time and play count
- Pages without the relevant fields do not show extra rows; values carried by members on custom pages are included too

### Collections accept any file type

- Dropping, adding, or batch-importing into a collection is no longer limited by the current page type
- Recognized files open in their own way, while unrecognized ones are stored as "Other"
- Extras in a movie collection or guides and patches in a game collection are no longer rejected

### Folder filter

- A new Folder / Not a folder filter in the left sidebar separates collections, anime, and directories from individual files
- Collections count as folders, as do anime and directories; single files such as exe, mkv, and pdf count as "Not a folder"
- The filter can be added directly in the page config and placed on any page

## Improvements

### Cards and layout

- The percentage-based card scaling in the top-right corner is gone; set cards per row in the page config's basic settings, from 2 to 10, defaulting to 4
- Cards split the row evenly, and cover and title font sizes stay the same, so adding more cards per row no longer shrinks the text
- Minimum and maximum card width are no longer needed for layout and have been removed from the page config
- Whole-interface zoom is still available whenever you want to scale the UI
- Card titles show at most two lines; long names wrap, and only text beyond two lines is truncated

### Page controls

- The search box moves to the top of the left sidebar and stays fixed while the filters below scroll
- Add, Create collection, Batch import, and Multi-select move onto the page title row instead of taking a whole toolbar, leaving more height for the list
- Each page can set its own cards-per-row value in the page config

## Bug fixes

- Resources inside a collection now follow the current sort instead of always staying in the order they were added
- At the page root, collections and individual files now sort by the same rule instead of collections always coming first
- Creating a page from the same template no longer brings over tags from the original page; each page only shows tags used by its own resources
