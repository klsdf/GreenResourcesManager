# 0.7.8 程序图标一键当封面，页面字段自己定！

这次更新主要围绕程序图标封面、页面字段配置和记录修正展开。

本次重点：

- 封面：游戏和软件可以一键把程序自带的图标设为封面
- 页面：每个页面可以自己增加、改名、排序和删除字段，同一页的资源共用这套字段
- 记录：详情页可以直接补改游玩时长、游玩次数和第一次游玩时间
- 网站：设置里可以选默认浏览器，也可以在软件内新开标签页打开
- 修复：Kirikiri Z / TyranoScript 引擎识别、AVIF 导入、HTTPS 打开和登录日历等问题

## 新功能

### 程序图标封面

- 游戏和软件在详情页、编辑封面时都能选择「使用应用图标作为封面」，一键读取程序自带的图标，不用再找图或截图
- 会优先读取较大的图标，保存后详情页和卡片都会用这张封面

### 页面字段

- 每个页面可以自己增加和修改字段，支持文本、多行文本、标签、数字和日期
- 同一页里的压缩包、视频、音乐共用这一页的字段，不跟文件类型绑在一起
- 可以添加已有字段，也可以新建字段；字段能改名、上下移动和删除。删掉只是这一页不再显示，资源里已经写下的内容还留着

### 详情页记录

- 详情页可以修改游玩时长、游玩次数和第一次游玩时间等内容，用来补上以前的记录

### 网站打开方式

- 设置 → 网站可以选择网站打开方式：用系统默认浏览器打开，或者在软件里新开一个标签页

## 体验优化

### 页面配置

- 引擎检测、选封面、选文件这类官方组件改成勾选；取消勾选只是这一页不显示，不会删掉已保存的内容
- 自定义字段可以改名、改类型、调整顺序
- 排序从这一页的字段以及添加时间、使用时长等记录项里选，每种排序都有升序和降序

### 多语言

- 页面标题、信息中心的分类和带数量的系统消息，会跟着当前语言显示

### 其他

- 发现新版本的通知可以点击，直接打开下载页
- 用户页精简为「统计与成就」，用户名改到设置 → 通用里填写
- 赞助页改版，集中展示作者的三款游戏
- 官网全新改版，帮助手册搬到新站点

## bug 修复

- 保存成 https 的网站会按 https 打开，不再先用明文 http 请求一次
- 详情里改完星级或完成状态后，左侧筛选栏的数量会马上跟着变
- Kirikiri Z 引擎游戏不再被错误识别成旧的吉里吉里
- 支持 AVIF 图片，导入时不再提示类型不匹配
- 部分 TyranoScript 游戏识别不出引擎的问题
- 登录日历会记住以前登录过的日子，不再每次打开都只剩今天
- 桌宠窗口不再空白，设置里的开关状态也会保持同步

This update focuses on app-icon covers, per-page field configuration, and record corrections.

Highlights:

- Covers: games and software can use their own program icon as the cover with one click
- Pages: each page can add, rename, reorder, and remove its own fields, shared by every resource on that page
- Records: edit play time, play count, and first played date directly from the details panel
- Websites: choose the default browser or a new in-app tab
- Fixes: Kirikiri Z / TyranoScript detection, AVIF imports, HTTPS links, the login calendar, and more

## Features

### App-icon covers

- Games and software can choose "Use app icon as cover" on the details panel or in the cover editor, reading the program's own icon instead of hunting for an image or taking a screenshot
- The larger icon is preferred; once saved, the details panel and cards both use it

### Per-page fields

- Each page can add and customize its own fields, including text, multiline text, tags, number, and date
- Archives, videos, and music on the same page share that page's fields instead of being tied to file type
- Add an existing field or create a new one; fields can be renamed, reordered, and removed. Removing a field only hides it from that page—values already saved in resources are kept

### Editable records

- The details panel can edit play time, play count, first played date, and more, so older records can be filled in

### Website open mode

- Settings → Website now offers an open mode: use the system default browser, or open a new tab inside the app

## Improvements

### Page configuration

- Official components such as engine detection, cover picker, and file picker are now checkboxes. Unchecking one only hides it from the page; saved content is untouched
- Custom fields can be renamed, change type, and reordered
- Sorting can use this page's fields plus built-in record items such as date added and play time; every sort offers ascending and descending order

### Localization

- Page titles, Message Center categories, and system messages with counts now follow the current language

### Also

- Update notifications can be clicked to open the download page directly
- The user page is now Statistics & Achievements; the username moved to Settings → General
- The sponsor page has been redesigned and now features three games from the developer
- A new official website, with the help center moved to the new site

## Bug fixes

- Websites saved with https now open over https instead of trying a plaintext http request first
- Sidebar counts update immediately after changing a rating or completion status in the details panel
- Kirikiri Z games are no longer misidentified as the older Kirikiri engine
- AVIF images are supported, and importing them no longer reports a type mismatch
- Some TyranoScript games no longer fail engine detection
- The login calendar now remembers previous days instead of resetting to today every time
- The desktop pet window is no longer blank, and its settings toggle stays in sync
