# 0.8.1 全新视频播放器，合集与阅读进度上线！

0.8.1 带来全新的内置视频播放器、资源合集和阅读进度记忆，并让小说阅读和压缩包解压更顺手。

本次重点：

- 视频：内置播放器换成自己的控件，支持倍速、全屏、画面适应、快捷键、上下集和截图
- 续播：视频按文件记住进度，番剧按集续看、按季统计；看到 95% 记为看完
- 兼容：播放前先探测编码，容器不对就无损重封装，HEVC 等编码临时转码，不改原文件
- 合集：资源页可以把电影、游戏、整本漫画或整季番剧整理成合集，搜索时仍能找到里面的资源
- 阅读：小说、PDF、EPUB 和漫画会记住上次位置；小说新增无极滚动和编码切换
- 细节：修改数据窗口不再误关，解压会显示密码和完整日志，音乐播放列表按预期工作

## 新功能

### 内置视频播放器

- 内置播放器改用自己画的控件，不再出现浏览器自带的控制条
- 支持倍速、音量、静音、全屏和画面适应；画面适应可以在适应画面、铺满画面和原始尺寸之间循环
- 播放器会记住音量、倍速和画面适应，下次打开还是这套设置
- 快捷键：空格暂停或继续，左右方向键前后跳 5 秒，上下方向键调音量，M 静音，F 全屏，N 下一集
- 同一目录下的视频会组成选集，可以看上一集、下一集，也可以在选集面板里直接点；还有下一集时，这一集播完会自动接着播
- 播放器里可以截取当前画面，保存到视频截图目录

### 续播与番剧统计

- 视频按文件记住播放位置，下次打开从上次的秒数继续
- 单个视频看到 95% 会记为看完
- 番剧按每一集记住进度，换集或关掉再打开都能接着看
- 番剧详情新增「播放次数」和「观看时长」，按整季累计；只统计正常播放时小幅前进的秒数，拖动进度条跨过一大段不会算进观看时长

### 播放兼容与转码

- 打开视频前先探测编码，浏览器能直接播的就直接播，不额外占用 CPU
- 容器不支持但画面编码没问题时，会无损重封装再播，不改动原文件
- HEVC、10 bit H.264 这类浏览器解不了的画面会临时转码后播放，原文件保持原样
- 直接播放出现只有声音没有画面时，会自动改用转码播放
- 设置 → 视频可以选择转码档位：标准尽量保持清晰，流畅更省 CPU
- 暂停时会停掉转码进程，不在后台一直占满处理器

### 资源合集

- 资源页可以创建合集，填写名称、简介、标签和封面；不选封面时使用第一个成员的封面
- 合集里放的仍是这一页原来的卡片，适合收电影、游戏、整本漫画或好几季番剧；番剧单集和漫画页不会拆出来
- 可以在右键菜单或多选操作里把资源加入合集，也可以在合集里直接添加
- 同一页里一个资源只属于一个合集，加入新合集会从原来的合集移出
- 进入合集后顶部会显示路径和返回按钮，成员按加入顺序排列；返回即可回到页面根目录
- 在根目录搜索或筛选时，已经收进合集的资源也会列出来，卡片上会标出所属合集
- 删除合集只会把成员放回页面，不会删除资源本身；资源被删除时也会从所有合集里移除

### 阅读进度与小说编码

- 小说、PDF、EPUB 和漫画都会记住上次读到的位置，下次打开直接接着读；EPUB 用内部位置恢复，比百分比更准
- 关闭阅读器标签页时会把最后一次翻页立刻写下，不会因为计时器还没到而丢失
- 文本小说阅读器新增无极模式：可以一直往下滚，滚到一页末尾自动接上后面的内容，同时只保留附近几页，几万页的小说也不会全部铺开
- 阅读方式可以在左侧阅读设置里切换，原来的分页模式仍可点上一页、下一页
- 小说会自动识别 UTF-8 和 GBK，也可以在阅读设置里手动选择 UTF-8、GBK（ANSI）、Big5 或 UTF-16，乱码时改一下即可
- 编码选择按书记住，这本是 GBK、另一本是 UTF-8 也不会互相影响

## 体验优化

- 详情里的「修改数据」只在遮罩上按下时才关闭；在输入框里按下后拖到外面松手，不会再丢掉还没保存的修改
- 解压窗口在密码对上后会直接写出用的是哪个密码，成功提示里也会带上
- 解压失败时会展示工具的完整输出，并可以一键复制，方便排查
- 装了 7-Zip 时，RAR 解压改由 7-Zip 执行并显示整个压缩包的百分比；只装了 WinRAR 时命令行不给百分比，进度条仍会保持滚动
- 音乐播放列表里的每一首旁边多了移除按钮，可以单独把某一首拿掉

## bug 修复

- 播放音乐时不再把资料库里的全部音频都塞进播放列表：点播放只播这一首；用「添加到播放列表」加过的歌会留在列表里，再点其中一首就从那里连着播

0.8.1 brings a brand-new built-in video player, resource collections, and reading-position memory, along with smoother novel reading and archive extraction.

Highlights:

- Video: the built-in player now uses its own controls, with speed, fullscreen, fit modes, shortcuts, previous/next episode, and screenshots
- Resume: videos remember their position per file; anime resumes per episode and tracks stats per season, with 95% counting as watched
- Compatibility: codecs are probed before playback; unsupported containers are remuxed losslessly and HEVC is transcoded on the fly without touching the original file
- Collections: group movies, games, whole manga, or full anime seasons on a resource page, while search can still find the members
- Reading: novels, PDFs, EPUBs, and manga remember where you stopped; novels gain infinite scrolling and encoding selection
- Also: the edit-data dialog no longer closes by accident, extraction shows the password and full logs, and the music playlist behaves as expected

## Features

### Built-in video player

- The built-in player now draws its own controls instead of showing the browser's default control bar
- Supports playback speed, volume, mute, fullscreen, and fit modes; fit cycles through contain, cover, and original size
- The player remembers volume, speed, and fit mode for next time
- Shortcuts: Space to pause/resume, Left/Right to seek 5 seconds, Up/Down to adjust volume, M to mute, F for fullscreen, and N for the next episode
- Videos in the same folder form a playlist: go to the previous or next episode, or pick one from the episode panel; when there is a next episode, it plays automatically after the current one ends
- Capture the current frame from the player and save it to the video screenshots folder

### Resume and anime stats

- Videos remember their playback position per file, so the next open continues from the same second
- A single video counts as watched once you reach 95%
- Anime remembers progress per episode, so switching episodes or reopening the player continues where you left off
- Anime details gain Play count and Watch time, accumulated for the whole season; only small forward steps during normal playback count, while dragging the seek bar across a large gap does not add to watch time

### Playback compatibility and transcoding

- Codecs are probed before playback; anything the browser can play directly is played directly without extra CPU work
- If the container is unsupported but the video codec is fine, it is remuxed losslessly instead of re-encoded, and the original file is untouched
- HEVC, 10-bit H.264, and other codecs the browser cannot decode are transcoded temporarily for playback, leaving the original file as-is
- If direct playback has sound but no picture, the player automatically falls back to transcoding
- Settings → Video lets you choose a transcode preset: Standard keeps as much detail as possible, while Smooth saves CPU
- Pausing stops the transcode process instead of leaving the CPU pinned in the background

### Resource collections

- Create a collection on any resource page with a name, description, tags, and cover; when no cover is chosen, the first member's cover is used
- A collection holds the same cards from that page, making it a good fit for movies, games, whole manga, or full anime seasons; individual episodes and manga pages stay inside their own details
- Add resources to a collection from the context menu or multi-select actions, or add them directly while inside a collection
- A resource belongs to only one collection per page; adding it to a new collection removes it from the old one
- Inside a collection, the header shows the path and a back button, and members keep their insertion order; go back to return to the page root
- When searching or filtering at the root, resources already in a collection are still listed and their collection is shown on the card
- Deleting a collection only returns its members to the page; it never deletes the resources, and deleted resources are also removed from every collection

### Reading position and novel encoding

- Novels, PDFs, EPUBs, and manga all remember where you stopped and reopen at that spot; EPUB uses its internal position, which is more accurate than a percentage
- Closing a reader tab writes the last page immediately, so a pending timer cannot lose it
- The text novel reader gains an infinite mode: keep scrolling down and the next page follows automatically, while only nearby pages are kept in memory, so a novel with tens of thousands of pages does not lay them all out
- Reading mode can be switched in the left reading settings; the original paged mode still has Previous and Next
- Novels are detected as UTF-8 or GBK automatically, and the reading settings also let you choose UTF-8, GBK (ANSI), Big5, or UTF-16 manually when text looks garbled
- The encoding choice is remembered per book, so one GBK novel and one UTF-8 novel do not affect each other

## Improvements

- The Edit data dialog now closes only when the backdrop itself is pressed; pressing inside an input and releasing outside no longer discards unsaved changes
- After a password matches, the extraction window shows which password was used, and the success message includes it as well
- Failed extractions show the tool's full output with a one-click copy button for troubleshooting
- With 7-Zip installed, RAR extraction runs through 7-Zip and reports the percentage for the whole archive; with only WinRAR, the command line provides no percentage and the progress bar keeps scrolling
- Each track in the music playlist now has a remove button, so you can take out a single song

## Bug fixes

- Playing music no longer dumps every audio file in the library into the playlist: clicking play plays only that track, while songs added with "Add to playlist" stay in the list, and clicking one of them continues from there
