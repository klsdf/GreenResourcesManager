# 0.7.7 右键压缩包，密码本自动解压！

这次更新主要围绕压缩包处理、主题外观、漫画阅读和观看记录展开。

本次重点：

- 压缩包：右键即可用密码本自动解压到同名文件夹，支持一次多选
- 主题：主题改为色板展示，新增晴空、墨白、青苔、暖沙、暮霞、敦煌、莫兰迪、马蒂斯、孟菲斯、夜航、夜墨 11 套配色
- 漫画：阅读器支持左右旋转，CBR/CBZ 可以用外部程序打开，修复白屏和黑屏
- 观看记录：可以标记已玩完、已看完或已读完，左侧筛选和完成标记会同步更新
- 其他：视频发行日期筛选、游戏截图文件夹、备份迁到用户目录、小说字数自动统计等

## 新功能

### 压缩包处理

- 资源管理器里可以右键压缩包，用密码本自动解压到同名文件夹，非常方便
- 资源管理器里可以一次多选多个压缩包，每个都会解压到自己的文件夹

### 主题与外观

- 设置里的主题改成色板，每种主题直接显示它的主要颜色
- 设置里多了晴空、墨白、青苔、暖沙、暮霞、敦煌、莫兰迪、马蒂斯、孟菲斯、夜航和夜墨 11 套配色

### 漫画阅读

- 漫画阅读器可以左右旋转图片，竖图转过来后能在横屏里看全
- 漫画里的 CBR 和 CBZ 可以用系统默认程序打开，也可以用设置里指定的程序打开

### 视频、游戏与其他

- 视频可以填写发行日期，电影页左侧可以按这个日期筛选
- 游戏详情里可以打开这个游戏的截图文件夹
- 设置里可以打开伪装图片所在的文件夹

## 体验优化

### 阅读与页面操作

- 漫画阅读器的页码框按总页数留出宽度，不再只能看见两位数字
- 选择在本应用内播放时，视频会在新标签页打开，不再弹出单独的播放窗口
- 详情页的玩家评价里可以标记已玩完、已看完或已读完，点亮时会放一场烟花和彩带
- 左侧筛选可以按已看完、未看完和未访问分开看，看完的卡片右上角会多一枚完成标记
- 批量导入本地资源时，全选放到窗口左下角，不再挤在文件列表里面
- 每个资源页标题右侧都能打开这一页的配置，不用再去设置里找页面管理
- 页面标题和描述改到同一行，少占一块高度

### 备份、语言与文档

- 自动备份改存到系统用户目录，Windows 上一般在 C 盘，不再和存档放在一起
- 设置里的语言单独放在通用下面。每个选项用那种语言写着「看懂就点这个」
- 完善本地化的文本
- 优化说明文档的各种内容

## bug 修复

- 编辑电影时，缩略图预览会显示已保存的封面，不再是房子占位图
- 读过的小说会显示已阅读，不再和最后阅读时间对不上
- 进入小说页会自动统计字数，不再一直显示未知字数
- 拖入游戏时会自动识别引擎并记住，不用再手动点一次识别
- 拖入游戏时会计算整个文件夹的大小，手动更新后也会记住
- 日志管道断开时，不再弹出主进程错误框
- 有密码的 ZIP 会用密码本里的密码继续解压，不再直接失败
- 小说阅读器打开后不再白屏，可以正常看小说
- 漫画阅读器打开后不再黑屏，可以正常看到漫画
- 漫画阅读器会显示当前这页图片的大小，不再一直停在获取中
- 漫画设置封面后，详情页左侧会显示这张封面，不再一直用默认图
- 启动时查看磁盘，本地硬盘不再被误报成没有权限或盘符不存在
- 番剧页打上的标签、演员、声优和制作组，现在会出现在左侧筛选栏
- 开启伪装模式后，资源封面会换成 disguise 文件夹里的图片
- 图片阅读器里连续翻页时，底部的图片名和大小不会再被选中

This update focuses on archive handling, themes, the comic reader, and completion tracking.

Highlights:

- Archives: right-click to extract with your password book into a same-named folder, with multi-select support
- Themes: color-palette previews plus 11 new color schemes
- Comic reader: rotate pages left or right, open CBR/CBZ externally, and no more blank or black screens
- Completion tracking: mark reviews as finished playing, watching, or reading, with matching sidebar filters and badges
- Also: video release-date filtering, a game screenshots folder, backups moved to the user directory, automatic novel word counts, and more

## Features

### Archives

- Right-click an archive in the resource manager to extract it automatically with your password book into a folder with the same name
- Select multiple archives at once in the resource manager; each extracts into its own folder

### Themes & Appearance

- Themes in Settings are now shown as color palettes, each previewing its main colors
- Added 11 new themes: Clear Sky, Ink White, Moss, Warm Sand, Sunset Glow, Dunhuang, Morandi, Matisse, Memphis, Night Voyage, and Night Ink

### Comic Reader

- The comic reader can rotate images left or right, so portrait pages fit fully in landscape
- CBR and CBZ comics can be opened with the system default app or a program chosen in Settings

### Video, Games & More

- Videos can now store a release date, and the movie page sidebar can filter by it
- The game details panel can open that game's screenshots folder
- Settings can open the folder where disguise images are stored

## Improvements

### Reading & Page Operations

- The comic reader's page-number box now sizes itself for the total page count, so three-digit page numbers are fully visible
- When "play in this app" is selected, videos open in a new tab instead of a separate player window
- Reviews on the details page can be marked as finished playing, watching, or reading; lighting one up sets off fireworks and confetti
- The sidebar can separate finished, unfinished, and unvisited items; finished cards get a completion badge in the top-right corner
- In the batch import dialog, Select All now sits at the bottom-left of the window instead of crowding the file list
- Every resource page now has its settings button next to the title, so you don't have to go through Settings → Page Management
- Page titles and descriptions now share one row, saving vertical space

### Backups, Language & Docs

- Automatic backups now go to the system user directory (usually the C drive on Windows) instead of next to your save data
- Language settings now live under General. Each option is written in its own language with a "if you understand this, click it" hint
- Polished localization text throughout the app
- Improved various parts of the documentation

## Bug fixes

- When editing a movie, the thumbnail preview now shows the saved cover instead of the house placeholder
- Novels you've read now show as read, matching the last-read time again
- Opening the novel page now calculates the word count automatically instead of showing "unknown" indefinitely
- Dropping in a game now detects and remembers its engine automatically; no need to click Detect again
- Dropping in a game now calculates the entire folder size and remembers it after a manual refresh
- A broken log pipe no longer pops up a main-process error dialog
- Password-protected ZIPs now keep extracting with passwords from the password book instead of failing immediately
- The novel reader no longer opens to a blank white screen
- The comic reader no longer opens to a black screen
- The comic reader now shows the current page image's size instead of being stuck on "fetching"
- After setting a comic cover, the details panel now shows it instead of the default image
- At startup, local drives are no longer misreported as permission-denied or missing
- Tags, actors, voice actors, and studios added on the anime page now appear in the sidebar filters
- With disguise mode on, resource covers now use images from the disguise folder
- When paging quickly in the image reader, the image name and size at the bottom no longer get selected
